App Settings

These switches apply to every organization.

When unchecked, the Public sharing tab is hidden for all admins.

When unchecked, renew, remark, create ticket, and the other ticket actions tied to this switch are hidden and blocked for everyone, including developers.

When checked, Request Services is hidden and new requests cannot be sent. The Admin Service Requests list stays available.

When checked, first-time users see the tour, and Take a tour appears in the User Guide.

When checked, the signup link is hidden and new accounts cannot be created. People who already have a verification email can still finish it.
